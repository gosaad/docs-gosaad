# Upload data peserta

Gunakan **Upload Data** untuk menambahkan banyak peserta sekaligus dari file Excel.

## Yang perlu disiapkan

- File data peserta berformat `.XLSX` dengan ukuran maksimum 5 MB.
- Template Excel resmi GoSAAD.

## Unduh format upload resmi

1. Buka **Data master** > **Peserta**.
2. Klik **Upload Data**.
3. Pastikan tab **Data peserta** sedang dipilih.
4. Klik **Download Template**.
5. Isi data peserta pada file `template-peserta.xlsx` yang diunduh.

Gunakan template resmi agar susunan kolom sesuai, validasi dilakukan per baris, dan kesalahan data lebih mudah ditelusuri.

## Upload file peserta

1. Pada area **Pilih file data peserta**, pilih atau tarik file `.XLSX` yang sudah diisi.
2. Pastikan file yang dipilih adalah template yang telah Anda lengkapi.
3. Klik **Upload & Simpan**.

## Hasil yang diharapkan

GoSAAD memproses file Excel dan menyimpan data peserta yang valid.

## Jika upload tidak berhasil

Pastikan file berformat `.XLSX`, tidak lebih dari 5 MB, dan menggunakan template resmi yang diunduh dari dialog **Upload Data**.

## Langkah berikutnya

Kembali ke [Mencari data peserta](./peserta) untuk memeriksa data yang telah ditambahkan.
