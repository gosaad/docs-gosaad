# Data master

Bagian **Data master** berisi data dasar yang digunakan saat menyiapkan dan menjalankan ujian. Buka menu ini dari navigasi sebelah kiri pada panel Administrator.

## Menu yang tersedia

| Menu | Tujuan |
| --- | --- |
| **Peserta** | Melihat dan mengelola data peserta ujian. |
| **Group** | Mengelola kelompok peserta. |
| **Jurusan** | Mengelola data jurusan. |
| **Agama** | Mengelola data agama. |
| **Matpel** | Mengelola data mata pelajaran. |

## Urutan yang disarankan

Mulai dari **Peserta** untuk memastikan data peserta tersedia. Setelah itu, lanjutkan ke menu lain sesuai kebutuhan pengelolaan ujian Anda.

## Langkah berikutnya

Buka panduan [Mencari data peserta](./peserta) untuk melihat daftar peserta dan menggunakan filter yang tersedia.
