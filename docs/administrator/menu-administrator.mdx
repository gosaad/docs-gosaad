# Mengenal menu Administrator

Setelah masuk sebagai administrator, gunakan menu di sisi kiri untuk berpindah antarbagian pengelolaan GoSAAD. Halaman ini adalah peta navigasi; panduan rinci untuk setiap menu akan dibuat bertahap.

## Urutan penggunaan yang disarankan

Untuk instalasi atau pelaksanaan ujian baru, mulai dari **Data master**, lanjutkan ke **Persiapan**, kemudian **Pelaksanaan**, dan akhiri dengan **Evaluasi**.

## Dashboard

**Dashboard** adalah halaman awal administrator. Gunakan untuk melihat ringkasan jadwal, peserta yang terhubung, bank soal, hasil, dan perhatian operasional yang perlu ditindaklanjuti.

## Data master

Bagian ini memuat data dasar yang digunakan dalam pengelolaan ujian.

| Menu | Kegunaan singkat |
| --- | --- |
| **Peserta** | Mengelola data peserta ujian. |
| **Group** | Mengelola pengelompokan peserta. |
| **Jurusan** | Mengelola data jurusan. |
| **Agama** | Mengelola data agama. |
| **Matpel** | Mengelola data mata pelajaran. |

Lihat panduan [Data master](./data-master) untuk mengenali bagian ini sebelum menggunakannya.

## Persiapan

Gunakan bagian ini untuk menyiapkan kebutuhan ujian sebelum pelaksanaan, termasuk **Event**, **Kompetensi**, **Bank soal**, dan **Kapita Selekta**.

## Pelaksanaan

Bagian **Pelaksanaan** memuat menu operasional ujian: **Jadwal**, **Token**, **Dokumen ujian**, **Login peserta**, **Monitor peserta**, dan **Ujian peserta**.

## Evaluasi

Setelah ujian berjalan, gunakan bagian **Evaluasi** untuk membuka hasil dan tindak lanjut ujian.

| Menu | Kegunaan singkat |
| --- | --- |
| **Koreksi** | Membuka pekerjaan koreksi. |
| **Hasil ujian** | Membuka hasil ujian. |
| **Ledger hasil peserta** | Membuka catatan hasil peserta. |
| **Summary bank soal** | Membuka ringkasan bank soal. |

## IRT

Menu **IRT** tersedia sebagai bagian tersendiri pada navigasi administrator.

## Akses & Sistem

Gunakan bagian ini untuk pengelolaan akses dan kebutuhan sistem.

| Menu | Kegunaan singkat |
| --- | --- |
| **Instansi** | Menu instansi; pada tampilan saat ini ditandai **Soon**. |
| **Pengguna** | Mengelola pengguna administrator. |
| **Hak Akses** | Mengelola hak akses pengguna. |
| **Diagnostik Sistem** | Membuka informasi diagnostik sistem. |
| **Manajemen Storage** | Mengelola penyimpanan. |
| **Backup** | Membuka pengelolaan backup. |

## Langkah berikutnya

Mulai dari panduan [Mencari data peserta](./data-master/peserta) pada bagian **Data master**.
