# Mengenal GoSAAD

GoSAAD menyediakan akses web untuk mengelola pelaksanaan ujian dan untuk peserta yang akan mengikuti ujian. Panduan ini membantu Anda mengenali akses yang tepat dan menyelesaikan tugas di dalam aplikasi.

## Pilih akses web Anda

| Anda menggunakan GoSAAD sebagai | Halaman yang digunakan | Tujuan |
| --- | --- | --- |
| Administrator | `.../admin` | Masuk ke panel pengelolaan jadwal, bank soal, peserta, dan hasil CBA. |
| Peserta | `.../login` | Masuk sebagai peserta sebelum melanjutkan ke proses ujian. |

Ganti `...` dengan alamat web GoSAAD yang diberikan oleh sekolah atau panitia ujian Anda. Alamatnya dapat berbeda pada setiap instalasi.

:::note
Jika Anda tidak yakin harus membuka halaman mana, tanyakan kepada panitia ujian atau administrator sekolah. Mereka dapat memberikan alamat web dan kredensial yang sesuai.
:::

## Siapkan server dengan aplikasi Desktop

GoSAAD Desktop adalah server siap pakai untuk menyiapkan layanan GoSAAD dengan alur satu klik. Aplikasi ini digunakan oleh pengelola sistem, bukan oleh peserta untuk mengerjakan ujian.

Buka [cba.gosaad.id](https://cba.gosaad.id) untuk mengunduhnya, lalu lihat panduan [menyiapkan server GoSAAD Desktop](./mulai-di-sini/aplikasi-desktop).

## Untuk administrator

Halaman **Login Administrator** ditujukan untuk pengguna yang mengelola operasional ujian. Masukkan email dan password administrator, lalu klik **Masuk**.

Gunakan kredensial yang diberikan oleh pengelola sistem atau panitia ujian Anda.

Setelah berhasil masuk, panel administrasi menyediakan menu untuk data master, persiapan, pelaksanaan, evaluasi, serta akses dan sistem. Setiap fitur akan dijelaskan dalam panduan terpisah.

Baca panduan langkah demi langkah: [Login Administrator](./administrator/login).

## Untuk peserta

Halaman login peserta digunakan sebelum memasuki ujian. Siapkan nomor ujian dan password dari panitia, lalu ikuti instruksi pada layar.

Baca panduan langkah demi langkah: [Login Peserta](./peserta/login).

<details>
  <summary>Jika halaman login atau kredensial tidak tersedia</summary>

  Pastikan alamat web yang dibuka sudah benar. Jika masalah berlanjut, hubungi panitia ujian untuk memeriksa nomor ujian, password, atau status akun Anda.
</details>

## Cara menggunakan panduan ini

Setiap halaman panduan menjelaskan satu tujuan, misalnya menambah peserta atau menyiapkan jadwal. Ikuti urutan langkah sesuai nama menu dan tombol yang tampil di GoSAAD.

Saat panduan memuat catatan, peringatan, atau informasi tambahan, bacalah sebelum melanjutkan tindakan pada aplikasi.
