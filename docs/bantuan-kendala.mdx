# Bantuan & kendala

Gunakan halaman ini untuk menemukan panduan yang sesuai sebelum menghubungi panitia atau administrator sekolah. Pilih masalah berdasarkan tahap penggunaan GoSAAD.

## Tidak dapat masuk

- Administrator yang tidak dapat masuk dapat mengikuti [Login Administrator](./administrator/login#jika-tidak-dapat-masuk).
- Peserta yang tidak dapat masuk dapat mengikuti [Login Peserta](./peserta/login#jika-tidak-dapat-masuk).

Pastikan alamat GoSAAD, nomor ujian atau email, serta password yang digunakan sudah sesuai dengan data dari panitia.

## Kendala saat menyiapkan atau menjalankan ujian

| Kondisi | Panduan yang digunakan |
| --- | --- |
| Peserta tidak muncul atau tidak dapat dipilih | [Kelola peserta](./administrator/data-master/peserta#jika-peserta-tidak-ditemukan) |
| Jadwal tidak dapat disimpan | [Tambah jadwal ujian](./administrator/pelaksanaan/tambah-jadwal#jika-jadwal-tidak-dapat-disimpan) |
| Token tidak diterima peserta | [Kelola token ujian](./administrator/pelaksanaan/token-ujian#jika-token-belum-dapat-digunakan) |
| Peserta perlu menggunakan perangkat lain | [Reset login peserta](./administrator/pelaksanaan/login-peserta#jika-reset-tidak-menyelesaikan-masalah) |
| Data peserta tidak tampil di monitor | [Memantau peserta ujian](./administrator/pelaksanaan/monitor-peserta#jika-data-monitor-tidak-tersedia) |

## Kendala setelah ujian

| Kondisi | Panduan yang digunakan |
| --- | --- |
| Hasil ujian tidak muncul | [Hasil ujian](./administrator/evaluasi/hasil-ujian#jika-hasil-tidak-muncul) |
| Saran koreksi Jaccard tidak tersedia | [Koreksi](./administrator/evaluasi/koreksi#jika-saran-jaccard-tidak-tersedia) |
| Summary bank soal belum tersedia | [Summary bank soal](./administrator/evaluasi/summary-bank-soal#jika-summary-tidak-tersedia) |

## Butuh diskusi lebih lanjut?

Bergabunglah di [Telegram GoSAAD](https://t.me/gosaad02) untuk berdiskusi mengenai penggunaan dokumentasi. Jangan membagikan password, token ujian aktif, atau data pribadi peserta di ruang diskusi.

## Langkah berikutnya

Jika panduan yang sesuai belum menyelesaikan kendala, catat nama menu, tindakan yang sudah dilakukan, dan pesan yang tampil. Informasi tersebut membantu panitia atau administrator menelusuri masalah dengan lebih tepat.
