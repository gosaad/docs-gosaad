# Siapkan server GoSAAD Desktop

GoSAAD Desktop menyediakan server siap pakai untuk menjalankan layanan GoSAAD dengan alur satu klik. Aplikasi ini disiapkan oleh administrator atau pengelola sistem; peserta tetap menggunakan GoSAAD melalui halaman web.

## Unduh server siap pakai

1. Buka [cba.gosaad.id](https://cba.gosaad.id).
2. Ikuti informasi unduhan yang tersedia pada halaman tersebut untuk mendapatkan GoSAAD Desktop.
3. Jalankan aplikasi Desktop untuk menyiapkan server GoSAAD.

## Setelah server siap

Administrator dan peserta kemudian menggunakan GoSAAD melalui web. Gunakan alamat web yang diberikan oleh pengelola server untuk membuka halaman administrator atau halaman login peserta.

:::note
Jika Anda tidak menemukan paket yang diperlukan atau mengalami kendala saat menyiapkan server, hubungi pengelola sistem atau panitia ujian.
:::

## Langkah berikutnya

Setelah server siap, lanjutkan dengan [mengenal akses GoSAAD](../intro.mdx) untuk memilih halaman administrator atau peserta.
